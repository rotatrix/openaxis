# OpenAxis for Python

Python client SDK for OpenAxis 1.0. Requires Python 3.11 or newer.

## Installation

```sh
python -m pip install --pre openaxis
```

See [SDK installation](https://openaxis.rotatrix.com/guide/sdk-installation/#python)
for setup details and source builds. Use documentation matching your SDK revision;
checkout APIs may be newer than published packages.
