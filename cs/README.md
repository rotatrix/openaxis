# OpenAxis C# SDK

OpenAxis 1.0 client SDK targeting .NET Framework 4.8 and .NET Standard 2.0.

## Installation

From your application directory, reference an OpenAxis checkout:

```sh
dotnet add reference path/to/openaxis/cs/OpenAxis/OpenAxis.csproj
```

See [SDK installation](https://openaxis.rotatrix.com/guide/sdk-installation/#csharp)
for setup details and source builds. Use documentation matching your SDK revision;
checkout APIs may be newer than published packages.
